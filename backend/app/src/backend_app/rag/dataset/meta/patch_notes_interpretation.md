# Understanding Patch Notes

## Buff and Nerf Indicators

Patch notes explicitly state which units and mechanics are buffed or nerfed:
- Buffs make things stronger
- Nerfs make things weaker
- Adjustments change mechanics

## Impact Assessment

Understanding the magnitude of changes helps predict meta impact:
- Small stat changes may be minor
- Mechanical changes can completely reshape strategy
- Item adjustments affect entire item classes

## Precedence in Meta Shifts

Some changes shift the meta more dramatically than others:
- Carry unit changes affect entire compositions
- Early-game changes affect early-game strategy
- Economy changes affect gold management

## Professional vs. Casual Impact

Changes that matter for pros might not affect casual play and vice versa, based on technical execution requirements.

## Item Reworks

Complete item system reworks, while rare, can dramatically restructure team building and item allocation strategy.

## Trait Adjustments

Changes to trait thresholds or bonuses can make or break trait-based compositions.

## Reading Between the Lines

Sometimes patch notes imply intended direction changes beyond explicit numbers, helping players predict broader meta shifts.

## Preparation for Patches

Understanding how patches will affect your favorite compositions helps you prepare strategies before patches go live.
