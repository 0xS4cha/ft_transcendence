# Composition Selection

## General Principle

A TFT composition should be evaluated based on:

- Available units
- Available items
- Augments
- Components
- Shop opportunities
- Current health
- Current economy
- Lobby competition
- Stage of the game

## Flexible Play

Strong players avoid forcing a composition solely because it was strong in a
previous game or patch.

## Item-Based Decision Making

Items can influence which carry or composition is most efficient to pursue.
